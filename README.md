# The Chanukah Raffle — Chabad of the Central Cascades

Entry form for the Chanukah raffle at the Issaquah menorah lighting.

- `index.html` — the entry form (static page; the QR codes point here)
- Entries post to the Apps Script backend, which saves them to the Google Sheet.
- In an iframe it automatically shows just the form card (or add `?embed=1`).
